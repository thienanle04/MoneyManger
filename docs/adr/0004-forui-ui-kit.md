# Forui as the UI kit

Screens use Forui (`FTheme`, `FScaffold`, `FCard`, `FTile`, Lucide icons), with `toApproximateMaterialTheme()` only so leftover Material widgets still theme. Forui was chosen over a Material-only UI for a consistent minimal mobile look. A custom brand theme (`dart run forui theme create`) is the point at which this gets revisited.
